Moon Sweepersの目標は、一見シンプルです。月の表面を隅々まで掃除すること。ただし、進め方はいくつもあり、序盤にアップグレードを間違えると進行が極端に遅くなります。この攻略ガイドでは、「掃除・回収・納品・アップグレード」の流れを整理し、収入を伸ばすために最初の資金をどこへ使うべきかを解説します。基本は、月面のルナダストを掃き集め、集積所へ運んで契約を達成し、利益をより良い道具やスーツの強化、やがては車両に再投資することです。

## Moon Sweepersの基本的な進め方

月での冒険は、契約を達成することから始まります。月面の掃除はボランティアではありません。回収したルナダストを売って得た利益が、必要な道具やアップグレードの資金になります。

ゲームの基本サイクルは次のとおりです。

- **掃除する**：手持ちの道具で月面のルナダストを取り除く
- **回収する**：掃除したダストを集め、集積所へ運ぶ
- **契約を達成する**：必要量のルナダストを納品する
- **再投資する**：収入を道具、アップグレード、車両に使う

月を掃除する方法は一つではありませんが、序盤は何をどの順番で解放するかが重要です。

## 序盤の月面掃除

最初にやるべきことは拠点の設置です。設置できたら、拠点に近いセクターから掃除しましょう。この段階では移動に使える車両がないため、移動時間が最大の敵になります。

おそらく最初に持っているのは歯ブラシだけですが、それで問題ありません。序盤はお金を使わず、歯ブラシでできるだけ多くのセクターを掃除するのが得策です。ネイルブラシやハンドブラシも購入できますが、少なくとも15セクターを掃除するまでは見送ったほうがよいでしょう。

大切なのは、**すべての道具を買わないこと**です。掃除道具ごとに掃除能力と運搬容量は異なりますが、購入するのは明確な利点があるものだけにしましょう。特におすすめなのは、歯ブラシから一気に家庭用ほうきへ乗り換えることです。比較的安価ながら、ルナダストの回収効率が大きく上がります。その後はワイドほうきと特大ワイドほうきを飛ばし、代わりに回収速度のアップグレードへ資金を回しましょう。

## おすすめのアップグレード優先順位

アップグレードにはいくつかのカテゴリがあり、資金が限られるうちは優先順位が重要です。各カテゴリの効果をまとめました。

**容器**

| アップグレード | 効果 |
| --- | --- |
| 歯ブラシ | 最初から使える掃除道具 |
| ネイルブラシ | 掃除能力が少し向上した道具 |
| ハンドブラシ | 掃除効率が大幅に向上 |
| 家庭用ほうき | 最初に買える安価なほうき。序盤の大きな強化 |
| ワイドほうき | 家庭用ほうきより広い作業範囲 |
| ダストコンパクター | すべての容器の運搬容量を増加 |
| オートパッカー | ダストの梱包を自動化し、時間を節約 |

**掃除**

| アップグレード | 効果 |
| --- | --- |
| ワイドヘッド | 道具の掃除幅を拡大 |
| ディープヘッド | 掃除の深さを向上 |
| ロングリーチ | 道具の作業距離を延長 |
| サージヘッド | 上記3つのアップグレードの効果を増幅 |

**スーツ**

| アップグレード | 効果 |
| --- | --- |
| サーボストライド | 移動速度が上昇 |
| ルナリープ | 空中での移動を強化 |
| ヘルメットランプ | 光源を追加 |
| エクソフレーム | バランスの取れた外装フレーム |

**経済**

| アップグレード | 効果 |
| --- | --- |
| マーケット契約 | ルナダストの売却報酬が増加 |
| サプライヤーネットワーク | セクター完了時に追加報酬を獲得 |
| リージョン報奨 | ルナダスト売却時に追加報酬を獲得 |
| ルナ・エクスチェンジ | 出荷時の報酬ボーナスが増加 |

長く遊べば、いずれすべてを手に入れられます。しかし序盤に頭一つ抜けているのは、**マーケット契約**です。達成する契約ごとの報酬が増えるため、納品するたびに多く稼げます。収入が増えれば、この一覧にあるほかのアップグレードにも早く手が届きます。

## 車両を使った掃除

序盤を抜けたら、**$200**でガレージを建設できます。すると車両が解放され、**$300**のプッシュスイーパーから、高額な**$6,000**のメガ・バキュームローバーまで購入できるようになります。

どの車両も目的は同じで、月面をより効率よく掃除するためのものです。移動速度が速いので遠くのセクターにもすぐ到達でき、パッチ1.0.3以降は車両をアップグレードして性能をさらに高められます。

元記事の筆者からの注意点は、高価な車両を急いで買わないこと。まずはプッシュスイーパーを数台用意すれば基本的な作業には十分です。メガ・バキュームローバーのような車両は、投資を回収できる終盤まで取っておきましょう。

## Moon Sweepersでお金を稼ぐ方法

序盤は未加工のルナダストを売るしかないので、まずは売却しましょう。ただし、ある程度の資金が貯まったら、**ムーンサンド**と**ムーンストーン**に注目してください。どちらもルナダストから作れる、はるかに価値の高い資源で、短期間で大きく稼げます。

自動化も終盤の経済活動の一つですが、本格的に取り組むのはエンドゲームに入ってからです。その段階に到達する頃には、このガイドで紹介した基礎から応用までを身につけているはずです。

## よくある質問

**Moon Sweepersの目標は何ですか？**
月の表面を隅々まで掃除することです。月面のルナダストを掃除して集積所へ納品し、契約を達成します。そこで得たお金で、より良い道具やアップグレードを購入します。

**Moon Sweepersで最初に選ぶべきアップグレードは何ですか？**
経済系では、達成する契約ごとの報酬が増えるマーケット契約がおすすめです。道具なら、最初の歯ブラシの次に家庭用ほうきを購入するのが最善です。

**掃除道具はすべて買うべきですか？**
いいえ。道具ごとに掃除能力と運搬容量は異なりますが、性能が重なるものも多くあります。家庭用ほうきのように明確な利点がある道具だけを買い、残りの資金を回収や経済系のアップグレードに使うほうが効率的です。

**メガ・バキュームローバーのような車両はいつ買うべきですか？**
$200でガレージを建設すると車両を購入できますが、$6,000のメガ・バキュームローバーのような高価な車両は終盤向けです。まずは安価なプッシュスイーパーから始め、大きな買い物は後に回しましょう。
